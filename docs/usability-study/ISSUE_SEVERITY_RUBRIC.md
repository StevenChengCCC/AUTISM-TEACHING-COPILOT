# Issue severity rubric

- Critical: privacy/safety breach, wrong learner/tenant data, lost teacher work, blocked required classroom task without recovery, or stale/wrong approved content. Release stops.
- High: core task fails or is materially misleading for multiple users; download/session/recording/recovery cannot be completed reliably. Must close or receive explicit authorized acceptance before Pilot ready; Controlled pilot requires none open.
- Medium: task completes with significant detour, assistance, print workaround, or duplicated entry. Prioritize by frequency and teacher-time cost.
- Low: cosmetic or minor clarity issue with no material effect on correctness, privacy, safety, or task completion.

Record evidence, affected task, reproducibility, workaround, owner, and resolution status. Do not downgrade severity because the case is synthetic.
