# 60-minute protocol

| Minutes | Activity |
|---:|---|
| 0–5 | Welcome, synthetic-data rule, participant questions, consent |
| 5–10 | Current-workflow baseline and role/context questions |
| 10–22 | Prepare the assigned lesson package |
| 22–30 | Choose and print the requested subset; inspect print output |
| 30–42 | Start session; record mixed valid/invalid trials; reload and recover |
| 42–48 | Complete closeout |
| 48–53 | Review progress and next-session guidance |
| 53–58 | Questionnaire and workflow comparison |
| 58–60 | Deletion choice, debrief, unresolved issue capture |

Do not compress a task to keep schedule at the expense of accurate timing. Record incomplete tasks as incomplete.
