# Real-teacher evaluation kit

Version: `teacher-usability-v1`. Audience: 3–5 special educators. Use only the included synthetic cases. This kit does not establish legal, privacy, clinical, or production approval.

The facilitator records raw timings and observations first, then applies the frozen thresholds in `docs/readiness/RELEASE_CLASSIFICATION.md`. Do not fabricate missing results, infer teacher intent, or coach participants toward a positive response.
