# Physical print inspection checklist

Artifact/preset: __________  Letter / A4  Standard / Large  Printer: __________

- [ ] Correct paper dimensions; safe margins; no clipped or overlapping content.
- [ ] Body text, card labels, data columns, and handwritten entry areas are usable.
- [ ] Table headers repeat and remain associated with their columns.
- [ ] Images retain aspect ratio and meaning; no missing glyphs or black squares.
- [ ] High contrast; meaning is not conveyed by color alone.
- [ ] Duplex order is usable, or single-sided use is clearly preferable.
- [ ] “Fit,” “actual size,” and printer scaling behavior checked.
- [ ] Low-ink/grayscale output remains interpretable.
- [ ] Teacher edits and current revision content are present.
- [ ] No direct identifier, raw record text, prompt, or signed URL appears.

Result: usable without edits / minor edits / major edits / unsafe or unusable
