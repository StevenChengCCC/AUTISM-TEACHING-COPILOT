## Publication checklist

- Treat every learner shown here as synthetic demo data.
- Crop or blur the signed-in account label in the upper-right corner before public publication.
- Do not imply that the “Generating…” frame is a finished or downloadable package.
- Do not combine these screenshots with rejected captures that show 409/422/503 errors, incomplete visuals, safety blockers, unsupported catalog warnings, or broken layout.
- For the strongest presentation sequence, use `01 → 02 → 03`, followed by a separately captured clean, fully approved PDF result.

The final PDF/result screenshot is intentionally not included yet because the available captures still show generation or approval blockers. Add it only after the package is fully generated, reviewed, approved, and downloadable.
