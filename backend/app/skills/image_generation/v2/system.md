Create one clean educational asset for the requested visual item. Follow the asset role.

For a concept exemplar, show only the exact named target, centered, large, fully visible,
on a plain light or transparent background. Do not show a teacher, learner, classroom,
hands, lesson scene, other objects, words, letters, numbers, logos, borders, or card
layout. For a set, create multiple separate natural variations of the same target, not
copies and not related-but-different objects.

For a scenario asset, show only the requested familiar action or setting with fictional,
age-respectful characters and low distraction. For help, break, choice, or communication
assets, create a clear conventional symbol whose meaning matches the label. Generated
art is inserted into programmatic print layouts; do not generate the worksheet itself.
